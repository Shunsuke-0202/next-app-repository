# 実装記録

## 対象
- 音声入力で家計簿を自動登録できるようにする

## 要件
- 「何に、いくら使ったか」を自然言語で入力できる
- 音声認識または手入力で支出/収入の種別・カテゴリ・金額を推定する
- すぐに家計簿へ反映できる

## 実装方針
- 自然言語パーサーを `app-service/app/utils.ts` に追加し、カテゴリと金額の抽出を担う
- Web Speech API を利用してブラウザのマイク入力からテキスト取得を行う
- 取得した文字列を `draft` に反映し、即座に保存できるようにする
- 最小限の状態管理で UI 変更を抑え、既存のフォームを活かす

## 変更ファイル
- `app-service/app/utils.ts`
- `app-service/app/page.tsx`
- `app-service/app/page.module.css`
- `app-service/app/__tests__/utils.test.ts`

## 設計判断
- 音声入力は外部APIやバックエンドを使わず、ブラウザ標準APIで最短実装に寄せた
- 収支の解釈は「カテゴリ + 金額」が必須条件で、曖昧な文は明確なエラーとして返す
- 既存の家計簿の編集/削除機能と共存させ、UXを壊さない構成を採用した

## 改善記録（2026-09-09）
- 保存データを型・日付・カテゴリ・金額で検証し、不正な `localStorage` 内容を除外
- 音声認識結果は自動保存せず、フォーム確認後に登録する方式へ変更
- 金額の有限値・整数・上限を検証し、カテゴリ内訳の収支符号を修正
- 日本語の `lang` 属性、ライブリージョン、必須入力、キーボードフォーカス表示を追加
- モバイルで音声入力と送信ボタンが縦配置になるようレスポンシブ対応
- 明るい背景、Geist系フォント、8px角丸で視認性と一貫性を改善

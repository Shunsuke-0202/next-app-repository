# 要件: 家計簿アプリの最小実装

## 目的
個人が日々の収支を簡単に記録し、月ごとの収支とカテゴリ別の内訳を確認できる家計簿アプリを作成する。

## 対象
- 個人利用者
- ログイン不要で即座に利用できる
- PC とスマートフォンの両方で利用できる

## 必須機能
1. 収入・支出の登録
   - 日付
   - 金額
   - 種別（収入 / 支出）
   - カテゴリ
   - メモ
2. 一覧表示
   - 収支を新しい順で表示
   - 各項目を編集・削除できる
3. 月次サマリ
   - 当月の収入合計
   - 当月の支出合計
   - 差額
4. カテゴリ別内訳
   - 支出カテゴリごとの合計
   - 収入カテゴリごとの合計
5. データ保持
   - ブラウザの localStorage に保存
   - 再読み込み後も残る
6. 画面設計
   - シンプルなダッシュボード UI
   - スマホでも崩れにくいレイアウト

## 受け入れ条件
- 収支を追加できる
- 一覧に表示される
- 月次の収支が計算される
- カテゴリ別の内訳が見える
- localStorage に保存される
- すぐに使える

## MVP スコープ
- CRUD
- 月次サマリー
- カテゴリ集計
- localStorage 保存
- 最低限の UI

## スコープ外
- ユーザー認証
- クラウド同期
- CSV 取り込み/出力
- 複数世帯共有
- 高度なグラフ分析
